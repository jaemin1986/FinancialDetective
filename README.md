## 어떻게 하나요?

### 오늘의 문제 (랭킹 반영)
- **하루 3문제**, 팀원 모두 같은 문제를 같은 순서로 풉니다.
- 새 문제는 **매일 새벽 3시**에 열립니다. 밤 12시~3시에 풀어도 그날 문제로 인정됩니다.
- 문제마다 **한 번만** 풀 수 있고, 낸 답은 되돌릴 수 없습니다. 중간에 창을 닫거나 기기를 바꿔도 이어서 풀 수 있습니다.

**한 문제는 두 단계입니다**
1. **회사 맞히기** — 최근 3개 사업연도 재무제표(손익·재무상태·현금흐름)를 보고 보기 4개 중 고르기. 기회 2번.
2. **시가총액 맞히기** — 억원 단위로 입력. 실제값의 ±10% 이내면 정답. 틀리면 UP ⬆ / DOWN ⬇ 힌트. 최대 5번.

**점수 (문제당 만점 110, 하루 만점 330)**

| 항목 | 점수 |
|---|---|
| 회사 1번째 / 2번째에 맞힘 | 40 / 20 |
| 시총 1~5번째에 맞힘 | 60 / 48 / 36 / 24 / 12 |
| 시총을 오차 3% 이내로 맞힘 | +10 보너스 |

### 연습 모드
- 닉네임 없이 바로 할 수 있고, 무제한으로 풀 수 있습니다. 랭킹에는 반영되지 않습니다.

### 랭킹
- **오늘 / 어제 / 주간(최근 7일 누적) / 월간(최근 30일 누적)**
- 하루 랭킹에는 3문제를 모두 푼 사람만 올라갑니다. 동점이면 시총 오차가 작은 순, 그다음 빨리 푼 순입니다.
- 다른 사람이 고른 보기와 입력한 숫자는 보이지 않습니다.
- **결과 복사** 버튼을 누르면 정답 없이 결과만 복사됩니다. 팀 대화방에 붙여넣으세요.
  `FinancialDetective 2026-11-14 | 226점 2위/5명 | Q1 ❌✅ 2/5 | Q2 ✅ 3/5 | Q3 ✅ 1/5🎯`

## 처음 시작하기

1. 위 링크를 열고 **"처음이에요"** 를 누릅니다.
2. **팀 코드**를 입력합니다. 팀 코드는 관리자에게 받으세요.
3. **닉네임**을 정합니다. 2~10자, 한글·영문·숫자·밑줄(_)만 쓸 수 있습니다. 랭킹에 이 이름이 나옵니다.
4. **PIN 4자리**를 정합니다.
   > ⚠️ 게임용 PIN입니다. **실제 쓰는 비밀번호를 넣지 마세요.**
5. 끝! 같은 기기에서는 90일 동안 자동으로 로그인됩니다.

**다른 기기(PC ↔ 휴대폰)에서 하려면** "이미 닉네임이 있어요"를 누르고 닉네임과 PIN을 입력하세요. 팀 코드는 다시 묻지 않습니다.

**PIN을 잊었거나 잠겼을 때** (5번 틀리면 10분 잠금) 관리자에게 말하면 임시 PIN을 받을 수 있습니다.

**닉네임·PIN 변경과 로그아웃** 은 화면 오른쪽 위 **닉네임 ⚙** 버튼에서 합니다. 닉네임은 30일에 한 번 바꿀 수 있습니다.

> 수집하는 정보는 닉네임과 PIN(암호화)뿐입니다. 이메일·실명·전화번호는 받지 않습니다.

## 관리자용

관리 작업은 `.env`(비밀 키)가 있는 관리자 PC에서만 합니다. 프로젝트 폴더에서 실행합니다.

```
.venv\Scripts\python.exe scripts\admin.py set-team-code                 # 팀 코드 설정·변경 (기존 참가자 영향 없음)
.venv\Scripts\python.exe scripts\admin.py list                          # 참가자 목록
.venv\Scripts\python.exe scripts\admin.py reset-pin <닉네임>             # 임시 PIN 발급 (잠금도 해제)
.venv\Scripts\python.exe scripts\admin.py rename <닉네임> <새닉네임>      # 닉네임 강제 변경
.venv\Scripts\python.exe scripts\admin.py delete <닉네임>                # 참가자와 기록 삭제
.venv\Scripts\python.exe scripts\admin.py reset-scores --date 2026-11-14 # 그날 기록 초기화
.venv\Scripts\python.exe scripts\admin.py reset-scores --nickname <닉네임>
.venv\Scripts\python.exe scripts\admin.py reset-scores --all            # 전체 기록 초기화 (새 시즌)
```

**자동 작업** — GitHub Actions(`.github/workflows/daily.yml`)가 매일 **15:00 KST**에 시가총액을 갱신하고, 내일 문제 3개를 만들어 Supabase에 올리고, 사이트를 배포합니다.
- 실패하면 GitHub에서 이메일 알림이 옵니다. 저장소 **Actions** 탭에서 **Run workflow**로 다시 실행할 수 있습니다.
- 재무제표를 새로 모으려면(새 사업보고서 반영 등) Run workflow에서 "상장사 목록·재무제표 다시 수집"을 체크하세요.

**Supabase 무료 플랜 주의** — 일주일 동안 아무 활동이 없으면 프로젝트가 일시 정지됩니다. 매일 자동 작업이 문제를 올리므로 보통은 문제없습니다. 정지되면 Supabase 대시보드에서 **Restore**를 누르세요.

**구조**
- `docs/` — 웹 화면 (HTML·CSS·JS, GitHub Pages)
- `scripts/` — 데이터 수집·문제 생성·업로드 (Python)
- `supabase/schema.sql` — DB 테이블 + 보안 규칙(RLS) + 판정·점수·랭킹 함수
- 정답은 브라우저로 보내지 않고 Supabase에서 판정합니다. 비밀 키는 `.env`와 GitHub Secrets에만 있습니다.
